# 不動産新着通知システム(福岡・マルチサイト対応)

複数の不動産サイトの検索結果を定期巡回し、条件に合う**新着物件だけ**をLINEに通知します。GitHub Actionsで動くため、PC常時起動は不要・費用もかかりません。

## 対応サイト

| 方式 | サイト | 状態 |
|---|---|---|
| 専用パーサー | SUUMO(売買・土地) | ✅ すぐ使える(URLを貼るだけ) |
| 汎用パーサー | athome / HOME'S / HOME4U / 東急リバブル / 楽待 / 健美家 / 三井のリハウス / 住友ステップ / 大京穴吹 / ピタットハウス / ノムコム / センチュリー21 / 大和ハウス / カチタス / 不動産連合隊 | ⚙️ URLとセレクタの調整後に有効化 |
| 対象外 | 恵比寿不動産(都心4区専門)/ 長谷工の仲介(首都圏専門) | 福岡の物件を扱っていないため未収録 |

汎用パーサー(type: generic)は**コードを書かずに** config.yaml のCSSセレクタ設定だけで任意のサイトを追加できます。

## 仕組み

```
GitHub Actions(30分ごと)
   └→ main.py が各サイトの検索結果を取得
        └→ seen.json と照合して新着を抽出
             └→ 価格・面積・間取り・キーワードで絞り込み
                  └→ LINE Messaging API でスマホに通知(まとめて1通)
```

## セットアップ

### 1. LINE(Messaging API)の準備

※ LINE Notifyは2025年3月に終了したためMessaging APIを使います。

1. [LINE Developers](https://developers.line.biz/) にログイン → プロバイダー作成
2. Messaging APIチャネルを作成
3. **Messaging API設定**タブで長期チャネルアクセストークンを発行して控える
4. QRコードから自分のLINEで友だち追加
5. **チャネル基本設定**タブ下部の「あなたのユーザーID」(Uから始まる)を控える

### 2. GitHubリポジトリ

1. プライベートリポジトリを作成し、このフォルダ一式をアップロード
2. Settings → Secrets and variables → Actions に登録:
   - `LINE_CHANNEL_ACCESS_TOKEN`
   - `LINE_USER_ID`

### 3. サイトの有効化

**SUUMO(すぐ使えます)**
1. SUUMOで福岡の希望条件で検索し、結果ページURLを config.yaml の url に貼る

**その他のサイト(1サイトずつ追加)**
1. そのサイトで検索し、結果ページURLを config.yaml に貼る
2. ブラウザで結果ページを右クリック→「検証」し、物件1件を囲む要素・物件名・価格などのCSSクラス名を確認して selectors を修正
3. 動作確認:
   ```bash
   python main.py --test "ノムコム 福岡 中古マンション"
   ```
   物件が5件表示されればOK。`enabled: true` に変更
4. うまく取得できないサイト(特にathome・HOME'Sはボット対策が強固)は無理に対応せず、**各サイト公式の新着メール通知機能**の利用を推奨します

### 4. 動作確認

- Actions タブ → 「新着物件チェック」→ Run workflow で手動実行
- 初回は既存物件の登録のみ(大量通知は来ません)
- 2回目以降、新着があったときだけ通知

## コマンド

```bash
python main.py                      # 通常実行
python main.py --test "ソース名"    # 1サイトだけ試す(通知なし)
python main.py --dry-run            # 全サイト実行するがLINEに送らない
```

## 注意事項

- **利用規約**: スクレイピングは各サイトの規約に抵触する場合があります。個人利用の範囲に留め、巡回頻度(30分〜1時間)とアクセス間隔(2秒/ページ)を守ってください。会員ログインが必要なページ(楽待の詳細等)の自動取得は行わないでください。
- **サイト側の変更**: HTML構造が変わると取得できなくなります。`--test` で確認し、config.yaml のセレクタを修正してください。
- **LINE無料枠**: 月200通まで。新着はまとめて1通なので通常は十分です。
- **JavaScriptレンダリングのサイト**: 一部サイトは検索結果をJavaScriptで描画するため、この方式(HTML直取得)では取れないことがあります。その場合も公式の新着メール機能が確実です。
